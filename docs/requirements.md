# Требования к системе

## Функциональные требования

- ФТ-1: Ведение базы данных профилей спортсменов (CRUD карточек, антропометрия, физиологические маркеры)
- ФТ-2: Кластеризация спортсменов по тренировочным группам (по квалификации, возрасту, целевым стартам)
- ФТ-3: Импорт и автоматический парсинг телеметрии из файлов FIT/TCX/GPX/CSV
- ФТ-4: Расчёт индексов тренировочного стресса TSS, ATL (7д), CTL (42д), TSB
- ФТ-5: Формирование базовых шаблонных микроциклов для группы
- ФТ-6: Автоматическое масштабирование группового шаблона под физиологию каждого атлета
- ФТ-7: Инструментарий ручного редактирования сгенерированных планов тренером
- ФТ-8: Генерация диагностических алертов — двусторонняя диагностика (перегруз + недогруз)
- ФТ-9: Визуализация аналитики (графики ATL/CTL/TSB, план-факт анализ)

## Нефункциональные требования

- НТ-1: Масштабируемость — стабильная работа при росте числа атлетов и объёма телеметрии
- НТ-2: Эргономичность — интуитивный интерфейс, русская локализация, без избыточных элементов
- НТ-3: Информационная безопасность — JWT-аутентификация, разграничение ролей coach/athlete

## Роли пользователей

### Тренер (coach)
- Управление группами и профилями атлетов
- Формирование и редактирование шаблонов микроциклов
- Просмотр расчётной матрицы и утверждение планов
- Просмотр алертов и аналитики
- Настройка порогов алертов

### Спортсмен (athlete)
- Просмотр своего текущего плана
- Ввод субъективных метрик (сон, усталость)
- Загрузка файлов телеметрии
- Просмотр истории тренировок

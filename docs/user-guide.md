# Руководство пользователя СППР

Краткое руководство по работе с системой поддержки принятия решений для
планирования подготовки в циклических видах спорта. Разделено по ролям:
**тренер** и **спортсмен**.

## Вход в систему

1. Откройте приложение и перейдите на страницу входа.
2. Введите email и пароль, нажмите «Войти».
3. Интерфейс и меню зависят от роли (тренер / спортсмен).

Спортсмен может зарегистрироваться сам («Нет аккаунта? Зарегистрироваться»)
или получить готовую учётную запись от тренера.

# Для тренера

Меню сверху: **Дашборд · Планирование · Аналитика · Атлеты · Настройки**

## Дашборд

Главный экран тренера:
- **«Требуют внимания»** — атлеты с активными диагностическими алертами
  (наведите на атлета, чтобы увидеть список алертов).
- **Недельная матрица группы** — тренировки атлетов по дням с цветовой
  индикацией статуса. Переключение недель — стрелками.

## Атлеты

Управление составом:
- **«+ Новый атлет»** — создать учётную запись атлета (email + пароль + профиль).
  Передайте атлету выданные логин и пароль.
- **«+ Создать группу»** — новая тренировочная группа.
- **«Распределить по группам»** — мастер кластеризации по квалификации,
  возрасту или цели подготовки.
- **«Привязать / Отвязать»** — закрепить атлета за собой.
- **✕** у атлета/группы — удалить (с подтверждением).

Клик по атлету открывает его **профиль**: антропометрия, физиологические
маркеры (ЧССmax, ЧССпокоя, ПАНО, HRV), пульсовые зоны, история тренировок,
предстоящие тренировки.

## Планирование — основной процесс

Процесс из четырёх этапов (виден в виде степпера сверху):

**Шаблон → Расчёт → Проверка → Утверждение**

### 1. Шаблон (редактор микроцикла)

- На странице **«Планирование»** нажмите **«Создать шаблон»**.
- Задайте название, группу, дату старта и длительность (дней), нажмите «Применить».
- Заполните дни тренировками:
  - тип (лыжи, лыжероллеры, бег, велосипед, силовая, восстановление, отдых),
  - зона интенсивности (Z1–Z5) и длительность, либо **интервальная** структура,
  - в одном дне можно задать **несколько тренировок** (утро/вечер) — кнопка
    «Добавить тренировку».
- Свободный день остаётся пустым (значок «+»); «Отдых» задаётся явно типом.
- **Копирование**: «Копировать неделю/дни» — перенести готовую неделю или
  диапазон дней на другие даты.
- Виды календаря: **Неделя / Месяц**. Внизу — сводный объём и доля зон.
- Нажмите **«Сохранить шаблон»**.

### 2. Расчёт (адаптация)

Кнопка **«Запустить расчёт →»**. Система масштабирует базовый шаблон под
каждого атлета по формуле:

```
T_индивид = T_шаблона × k_qual × k_form
```

где `k_qual` — коэффициент квалификации, `k_form` — коэффициент текущей формы
(по TSB). После расчёта открывается матрица.

### 3. Проверка (расчётная матрица)

- Таблица «атлеты × дни» с индивидуальными тренировками (черновики).
- **«Как рассчитана нагрузка»** — раскрывающаяся панель: по каждому атлету
  показаны квалификация → `k_qual`, TSB → `k_form` и итоговый множитель.
- Клик по тренировке — детали и ручное редактирование.
- Баннер **«Шаблон изменён после расчёта»** напоминает пересчитать, если
  правили шаблон после адаптации.

### 4. Утверждение

- **«Утвердить неделю N»** — опубликовать черновики текущей недели.
- **«Утвердить весь план»** — опубликовать все черновики разом.
- При **конфликте** (у атлета уже есть тренировки из другого плана на эти дни)
  система предупредит перед утверждением.

После утверждения тренировки становятся видны атлету.

## Аналитика

Графики и сводки: динамика нагрузки **ATL / CTL / TSB**, план-факт по неделям,
объёмы и время в зонах, активные алерты по атлетам и группам.

## Настройки

Пороги диагностических алертов — правила перегрузки **П1–П5** и недогруза
**Н1–Н5** можно настроить под свою методику.

# Для спортсмена

Меню сверху: **Сегодня · Мой план · История · Аналитика · Дневник**

## Сегодня / Мой план

- **«Сегодня»** — задание на текущий день.
- **«Мой план»** — предстоящие **утверждённые** тренировки (черновики тренера
  не показываются, пока он их не утвердит).

## Дневник (субъективные метрики)

Ежедневный опросник — основа диагностики состояния:
- качество сна, длительность сна,
- уровень усталости,
- значение HRV (вариабельность пульса).

Регулярный ввод позволяет системе вовремя выявлять перегруз/недовосстановление.

## История (журнал тренировок)

- **Загрузка телеметрии** из файлов **FIT / GPX / TCX / CSV** — система сама
  посчитает дистанцию, пульс, время в зонах и TSS.
- Просмотр истории выполненных тренировок (план vs факт).
- Можно добавить **самостоятельную тренировку** вне плана.

## Аналитика

Личные графики нагрузки (ATL / CTL / TSB), план-факт и активные алерты.

# Ключевые понятия

| Термин | Значение |
|---|---|
| **Зоны ЧСС (Z1–Z5)** | Пульсовые зоны по шкале Olympiatoppen (% от ЧССmax) |
| **Адаптация** | `T = T_шаблона × k_qual × k_form` — масштабирование под атлета |
| **TSS** | Training Stress Score — стресс одной тренировки |
| **ATL** | Острая нагрузка (среднее за 7 дней) — «усталость» |
| **CTL** | Хроническая нагрузка (за 42 дня) — «форма» |
| **TSB** | Баланс нагрузки (CTL − ATL) — «свежесть» |
| **Статусы** | Черновик → Опубликовано (видно атлету) → Выполнено |
| **Алерты П1–П5** | Признаки перегрузки |
| **Алерты Н1–Н5** | Признаки недогрузки |
